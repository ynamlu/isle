## 一、认识心屿

心屿是一款 **AI 情感陪伴应用**。与普通聊天机器人的最大区别是：

| 普通 AI 助手 | 心屿 |
| --- | --- |
| 每次对话都从零开始 | **记得你**：会记住你说过的话、喜欢的东西、在意的事 |
| 固定人格 | **可自定义角色**：恋人 / 闺蜜 / 朋友 / 家人，性格背景由你设定 |
| 记忆存在云端 | **记忆存在手机本地**，端侧向量检索，不联网 |

**核心概念**

- **角色**：一个可以自定义的「人」，拥有独立的性格、背景、说话风格与头像
- **长期记忆**：角色从你们的对话中自动提炼出的事实，下次聊天时会带着这些记忆出现
- **我的资料**：你对自己的介绍，**所有角色共享**，让新角色一见面就了解你

## 二、安装与启动

### 2.1 安装

将 `app-arm64-v8a-debug.apk` 传到手机后点击安装。

> 若提示「未知来源应用」，请在系统设置中允许安装来自该来源的应用。

### 2.2 系统要求

| 项 | 要求 |
| --- | --- |
| Android 版本 | 8.0（API 26）及以上 |
| CPU 架构 | ARM64（现代手机）或 ARMv7 |
| 存储空间 | 约 150 MB |
| 网络 | 需要联网（调用 AI 模型服务时） |

### 2.3 首次启动


![图 1 · 首次启动：首页已内置默认角色「小屿」，开箱即可对话](screenshots/01_home.png)

*（图 1 · 应用首页）*

打开应用后，你会看到首页。**应用已内置一个默认角色「小屿」**，无需任何配置即可开始聊天。

## 三、首次配置

如果你使用的是自带演示密钥的版本，可以跳过本节直接聊天。

### 3.1 配置模型服务


![图 2 · 设置页：模型服务入口位于第二行](screenshots/07_settings_bottom.png)

*（图 2 · 设置页的四个功能入口）*

1. 首页右上角 **⚙ 设置**
2. 点击 **「模型服务」**
3. 填写：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| **API Key** | 模型服务的密钥 | `sk-xxxxxxxx` |
| **API 地址** | 服务端点 | `https://api.deepseek.com/v1` |
| **模型 ID** | 要使用的模型 | `deepseek-flash` |

4. 返回即可开始使用

> **密钥安全**：API Key 只保存在你的手机里，不会上传到任何第三方服务器。
>
> **优先级**：你在应用里填的 Key 会覆盖应用内置的演示密钥。

### 3.2 调整回复风格（可选）

在 **设置 → 回复风格** 中调整「温度」：

- **数值越低（0.0–0.5）**：回复越稳定、越克制
- **数值越高（1.0–1.5）**：回复越活泼、越随机
- **推荐**：0.7 – 1.0

## 四、角色管理

### 4.1 创建新角色


![图 3 · 角色编辑页：名称、关系类型、性格、背景、说话风格与头像均可自定义](screenshots/04_character_edit.png)

*（图 3 · 角色编辑页）*

1. 首页点击 **「＋ 创建新角色」**
2. 填写角色信息：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| **角色名称**（必填） | TA 的名字 | 小屿 / 阿泽 / 小星 |
| **关系类型** | 决定 TA 与你的关系定位 | 恋人 / 闺蜜 / 朋友 / 家人 / 自定义 |
| **性格描述** | TA 的性格特点 | 温柔、细心、有耐心，偶尔有点小傲娇 |
| **简介 / 背景故事** | TA 的身份背景 | 住在海边的插画师，喜欢在傍晚散步 |
| **说话风格** | TA 的语言习惯、如何称呼你 | 语气亲近，喜欢用「嗯嗯」，会叫我「笨蛋」 |
| **开场白** | 进入聊天时 TA 说的第一句话 | 嗨，你来啦～今天过得怎么样呀？ |

3. **上传头像**：点击头像圆形区域 → 选择「相册」或「拍照」
4. 点击右上角 **✓ 保存**

**关于亲密关系定位的提示**

选择「恋人」或「自定义」关系时，应用会先弹出如下提示，确认后方可选中：

![图 7 · 未成年人保护提示：选择「恋人」等亲密关系定位时弹出](screenshots/08_disclaimer.png)

*（图 7 · 亲密关系定位的提示弹窗）*

> **提示**：角色信息填得越具体，TA 的表现就越贴近你想要的形象。
> 尤其是「说话风格」，它直接影响 TA 的用词习惯。

### 4.2 编辑角色

有两种入口：

- **聊天页内**：右上角 **✏️ 铅笔图标** → 直接编辑当前角色
- **从首页**：进入角色聊天 → 点铅笔图标

### 4.3 删除角色

在角色编辑页 → 右上角 **🗑 删除图标** → 确认。

> ⚠️ **删除后无法恢复**：该角色的**全部聊天记录与长期记忆都会被一并清除**。

## 五、开始聊天

### 5.1 进入聊天

首页点击任意角色卡片即可进入聊天页。

### 5.2 发送文字


![图 4 · 聊天页：流式逐字回复，右上角为记忆与编辑角色入口](screenshots/02_chat.png)

*（图 4 · 聊天页）*

在底部输入框输入内容 → 点击 **➤ 发送按钮**（或按回车键）。

**回复方式**：AI 会**逐字流式回复**，像真人打字一样，无需等待整段生成完毕。

### 5.3 发送图片

1. 点击输入框左侧 **🖼 图片按钮**
2. 选择「相册」或「拍照」
3. 图片会显示为待发送预览，点击 **➤** 发送

AI 能理解图片内容并针对图片回应，例如：

> 你发一张美食照片 → TA 可能回复：「看起来好好吃！这是你自己做的吗？」

**移除待发送图片**：点击预览图右上角的 **✕**

### 5.4 查看大图

点击聊天中的任意图片 → **全屏查看**，支持：

- **双指缩放**（放大 1–5 倍）
- **单指拖动**（放大后移动视野）
- 点击背景或右上角 **✕** 关闭

### 5.5 聊天页功能入口

| 位置 | 图标 | 功能 |
| --- | --- | --- |
| 左上角 | ← | 返回角色列表 |
| 右上角 | 🧠 | 查看该角色的长期记忆 |
| 右上角 | ✏️ | 编辑当前角色 |

### 5.6 关于回复速度

回复需要调用 AI 模型服务，通常几秒内开始输出。若长时间无响应：

- 检查网络连接
- 检查「设置 → 模型服务」中的密钥是否有效
- 查看是否弹出错误提示

## 六、我的资料

「我的资料」是**你对自己的介绍**，所有角色共享。填好之后，每次聊天角色都会知道：

- 你希望被怎么称呼
- 你的性格
- 你想对 TA 说的话

### 6.1 填写步骤


![图 5 · 我的资料：填写称呼、性格与想说的话，所有角色共享](screenshots/06_profile.png)

*（图 5 · 我的资料页）*

1. 首页 → **⚙ 设置** → **「我的资料」**
2. 填写三项：

| 字段 | 示例 |
| --- | --- |
| **希望被怎么称呼** | 小彤 |
| **我的性格** | 慢热但很重感情，容易共情，偶尔会多想 |
| **想对 TA 说的话** | 我最近在准备比赛，压力有点大 |

3. 自动保存，无需手动确认

### 6.2 效果

填写后，与新角色首次对话时，TA 就已经「认识」你了，不需要重新自我介绍。

> **与「长期记忆」的区别**：
> - **我的资料** = 你主动告诉 TA 的，**所有角色共享**
> - **长期记忆** = 角色从对话中自己记住的，**每个角色独立**

## 七、长期记忆

这是心屿最核心的能力。角色会从你们的对话中自动提炼值得记住的事。

### 7.1 记忆是怎么产生的

每轮对话结束后，应用会分析这次对话，提炼出关于你的关键信息，例如：

```
记得你喜欢在周末去爬山，说起时语气都变轻快了
知道你最近总加班到很晚，很心疼
记得七月二十号是你的生日，是夏天里海边最舒服的时候
```

> 注意措辞——**记忆是以角色的口吻记下的**，而不是「用户喜欢爬山」这种冷冰冰的条目。

### 7.2 查看记忆


![图 6 · 长期记忆页：角色自动积累的记忆，按类别打标，可逐条删除](screenshots/03_memory.png)

*（图 6 · 长期记忆页）*

聊天页右上角 **🧠** → 进入「长期记忆」页。

每条记忆都有分类标签：

| 标签 | 含义 |
| --- | --- |
| 信息 | 基本信息（姓名、职业等） |
| 喜好 | 喜欢 / 不喜欢的事物 |
| 经历 | 发生过的事 |
| 关系 | 你们之间的关系进展 |
| 约定 | 约定过的事情 |

### 7.3 管理记忆

| 操作 | 方法 |
| --- | --- |
| 删除单条 | 点击该条右侧的 **🗑 图标** |
| 清空全部 | 右上角 **清空图标** → 确认 |

> **建议**：如果发现记错的内容，及时删除，避免影响后续对话质量。

### 7.4 记忆如何影响对话

每次你发送消息时，应用会在本地**检索出最相关的记忆**（最多 6 条）注入对话，
所以角色能自然地提起你之前说过的内容。

### 7.5 隐私说明

**记忆的向量化、存储与检索全部在手机本地完成，不联网、不外传**。
只有「从对话中提炼记忆」这一步会用到你配置的 AI 模型服务。

## 九、隐私与数据安全

### 9.1 数据存在哪里

| 数据 | 存储位置 |
| --- | --- |
| 角色信息、头像 | 手机本地（应用内部存储） |
| 聊天记录 | 手机本地数据库 |
| 长期记忆（含向量） | 手机本地数据库 |
| 我的资料 | 手机本地配置 |
| API Key | 手机本地配置 |

**应用不含任何自建服务端**，所有数据都在你的设备上。

### 9.2 什么会联网

仅在发送消息时：**对话内容与「我的资料」会传输至你配置的模型服务**（如 DeepSeek）用于生成回复。

**端侧语义向量（记忆检索）完全离线**，不产生任何网络请求。

### 9.3 卸载应用

卸载应用会**一并删除**所有角色、聊天记录与记忆，且无法恢复。

## 十、常见问题

**Q1：输入框点不动 / 键盘弹不出来**

先确认系统默认输入法是否正常。可到「系统设置 → 键盘与输入法」检查，
或临时切换到系统自带键盘测试。这是设备侧问题，并非应用故障。

**Q2：发送消息后一直没回复**

1. 检查网络
2. 检查「设置 → 模型服务」的 API Key 是否填写正确、是否过期
3. 确认模型 ID 与 API 地址匹配

**Q3：角色好像「忘了」之前说的事**

- 记忆是自动提炼的，若某条重要信息没被记录，可以在对话中再提一次
- 也可能该条记忆已被你手动删除

**Q4：发送的图片点开很模糊**

早期版本保存的图片分辨率较低。**重新发送一张图片**即可获得清晰的大图。

**Q5：两个角色的记忆会串吗**

不会。每个角色拥有**完全独立的记忆库**，互不干扰。删除角色时会级联清除其记忆。

**Q6：可以同时和多个角色聊天吗**

可以。首页的所有角色都是独立的，各自拥有独立的会话与记忆。

**Q7：回复太活泼 / 太死板**

到「设置 → 回复风格」调整温度。想更稳定就调低，想更活泼就调高。

**Q8：如何彻底清空所有数据**

目前需要逐角色删除，或在系统设置中清除应用数据。

## 十一、免责声明

- 本应用为**竞赛作品展示**，不替代专业心理咨询服务。
- 若你正处于严重的情绪困扰中，请及时寻求专业心理援助。
- AI 的回复由大语言模型生成，可能存在不准确或不当之处，请理性看待。
- 本应用不收集、不上传任何用户数据至开发者；但消息内容会传输至你自行配置的模型服务商。
