# 心屿（Isle）· 产品说明

> 一座会记住你的心灵小岛
> 面向大学生的 AI 情绪支持应用

---

## 一、一句话定位

心屿不是“AI 恋人”，也不是“心理咨询师”。

它是一款**面向大学生的情绪支持应用**：用闺蜜、老师、家人三种角色，陪用户把情绪说出来、理清楚，
并在危机时及时把用户交给真人。

---

## 二、用户与场景

### 2.1 目标用户

- 大学生；
- 不想实名、不想暴露隐私的人；
- 暂时不想去心理咨询中心，但需要一个低门槛出口的人；
- 想要被听见、被记住，而不是每次重新解释自己的人。

### 2.2 典型场景

| 场景 | 用户需要什么 | 心屿提供什么 |
| --- | --- | --- |
| 期末复习焦虑 | 把混乱的焦虑拆小 | 场景引导 + 20 分钟小任务 |
| 面试失败 | 先被接住，再复盘 | 共情 + 区分事实/自我评价 |
| 宿舍矛盾 | 想说又怕撕破脸 | 感受/需求/边界 + 沟通句式 |
| 家庭压力 | 不想被说教 | 稳定、温和的家人角色 |
| 失眠 | 停止反刍 | 呼吸/落地练习 |
| 孤独 | 低门槛连接 | 树洞模式 + 一个小连接动作 |

## 三、产品结构

### 3.1 启动

```text
品牌封面 → 本地账户/游客 → 四栏主界面
```

### 3.2 四栏导航

| 入口 | 作用 |
| --- | --- |
| 首页 | 角色与快速场景 |
| 场景 | 8 个完整场景 |
| 记忆 | 跨角色记忆总览、折叠、管理 |

## 四、角色体系

| 角色 | 定位 | 说话方式 |
| --- | --- | --- |
| 闺蜜「小屿」 | 倾听、共情、吐槽 | 轻松、短句、口语化 |
| 家人「阿岚」 | 稳定、不说教的关心 | 温和、生活化 |
| 老师「林深」 | 学业/成长陪伴 | 结构化、提问式 |

不提供恋人角色；自定义角色也不提供恋爱关系类型。

---

## 五、场景与对话模式

### 5.1 八个场景

期末焦虑、面试失败、宿舍关系、家庭冲突、失眠、低动力、孤独、只想被听见。

每个场景都有：

- AI 主动开场；
- 目标；
- 4 步左右的轻量路径；
- “只推进一个小步骤”的约束。

### 5.2 五种模式

- 自由聊；
- 听我吐槽（只倾听、不打断、不评价）；
- 帮我分析（事实/感受/需求）；
- 陪我呼吸（30 秒落地）；
- 场景引导。

### 5.3 情绪手账

结束一段深度对话后，用户可以点聊天页右上角的 ✨，自动提炼一句金句，
生成一张 1080×1440 的品牌渐变手账图；右下角带渠道二维码，保存到
`Pictures/心屿/` 后可分享至朋友圈或小红书。

## 六、安全设计

### 6.1 三层机制

| 层级 | 作用 |
| --- | --- |
| 角色范围 | 不提供恋人，减少恋爱/暧昧风险 |
| 本地风险路由 | 高危/危机不调用模型，固定话术 |
| 输出校验 | 拦截 AI 身份暴露、危险方法、倾听模式建议 |

### 6.2 风险分级

- L0 日常；
- L1 焦虑/低落；
- L2 高危（无望感、自伤念头）；
- L3 危机（明确自伤/自杀表达）。

L2/L3 会暂停角色扮演，展示 12356、120/110、学校心理中心/辅导员。

### 6.3 安全边界

- 不诊断、不治疗、不承诺疗效；
- 不提供自伤方法/剂量/地点；
- 不鼓励只依赖 AI；
- 危机内容不写入长期记忆。

### 6.4 模型接入与密钥保护

公开分发包不把上游真实 Key 放进 APK：

```text
手机 App（代理令牌）
  → Cloudflare Worker（鉴权 / 白名单 / 限额）
  → 模型服务（真实 Key 只在 Secret）
```

- 真实 Key 不进入安装包、源码仓库或客户端配置；
- APK 只携带可撤销的代理令牌；
- 代理限制模型白名单、单次回复长度和每 IP 每日调用次数；
- 换上游 Key 不需要重新打包，用户无感；
- 代理令牌仍可能被提取，但拿不到真实 Key，发现异常可立即轮换。

---

## 七、本地匿名账户

- 昵称 + 密码，不需要手机号/邮箱/实名；
- PBKDF2WithHmacSHA256，210,000 次迭代；
- 恢复码只显示一次，可验证当前密码后重新生成；
- 5 次失败锁定；后台 60 秒应用锁；
- 删除账户清空角色、聊天、记忆、图片、模型配置和资料。

本地账户只做本机身份识别，不做学籍/实名核验。

---

## 八、记忆

- 端侧向量：`bge-small-zh-v1.5` int8，512 维；
- 召回：语义 0.8 + 关键词 0.2 + 重要度 0.1；
- 角色隔离；
- 记忆 Tab 按角色折叠；
- 展开只读查看，点「管理」进入单角色记忆管理；
- 支持搜索、编辑、删除、清空；
- 高危/危机对话不写入长期记忆。

---

## 九、设计取舍

| 取舍 | 原因 |
| --- | --- |
| 不提供恋人角色 | 降低暧昧/依赖/内容风险，聚焦情绪支持 |
| 本地账户而非云账号 | 不需要手机号/邮箱，符合匿名倾诉场景 |
| 本地规则而非全交给 LLM | 危机场景不能靠模型自由发挥 |
| 四栏而非单页 | 场景和记忆需要独立入口，降低发现成本 |
| 单角色组折叠 | 避免记忆页变成一长串卡片 |

---

## 十、创新点

1. **端侧语义记忆**：向量化、存储、召回都在手机本地；
2. **多智能体安全路由**：情绪检测、策略路由、角色生成、输出校验分离；
3. **匿名本地账户**：不需要手机号/邮箱/实名；
4. **场景化情绪支持**：不是纯自由聊天，而是有目标的轻量引导；
5. **记忆生命周期**：抽取、去重、召回、折叠、管理、安全过滤；
6. **密钥不进包**：真实模型 Key 由 Serverless 代理保管，客户端只带可撤销令牌。

## 十三、产品商业化与用户增长规划

> 原则：核心情绪支持免费；不卖数据、不投诱导式广告、不利用危机场景变现。

### 13.1 商业化结构

| 收入来源 | 内容 | 启动阶段 |
| --- | --- | --- |
| C 端订阅 | 更长记忆、语音朗读、主题手账、导出/同步等增值能力 | 验证留存后 |
| 校园服务 | 心理中心/社团的匿名团体工作坊工具包、主题手账模板 | 3–5 所试点校 |
| 增值包 | 角色主题、手账模板、纪念日卡片 | 可与订阅合并 |
| 企业 EAP | 未来可选，不涉及员工个人对话内容 | 暂不启动 |

定价假设：低价订阅（如 9.9–19.9 元/月），先用 1–2 个增值点验证付费意愿，不一次性堆功能。

成本结构：

- 主要成本是模型 token；
- 无短信、无强制云存储，Serverless 代理按量计费、无固定服务器成本；
- 端侧记忆降低向量检索成本；
- 校园推广以社团合作和学生 KOC 为主，不投大规模广告。

### 13.2 低成本裂变的核心：情绪手账

```text
深度对话
  → 提炼金句
  → 生成情绪手账图
  → 保存到相册
  → 分享朋友圈 / 小红书
  → 右下角二维码
  → 落地页
  → 游客体验
  → 生成自己的手账
```

为什么这条链路成本低：

1. **用户自己生产内容**：手账图就是品牌物料，不需要每次买量；
2. **分享是情绪表达，不是硬广**：用户愿意晒“今天被接住了”；
3. **二维码可归因**：从哪张手账来、扫码后是否激活，都能统计；
4. **无需注册即可体验**：落地页 → 游客模式 → 先聊一次，降低首跳流失；
5. **安全边界不外溢**：危机内容不生成手账，不把痛苦当传播素材。

设计原则：

- 图要好看，但不要过度装饰；
- 金句要像用户自己说的话，不要像平台广告；
- 二维码小而不抢，放在右下角；
- 不强制关注、不强制邀请、不做“分享解锁”。

### 13.3 冷启动：先做 3 所校园，不铺全国

| 阶段 | 动作 | 目标 |
| --- | --- | --- |
| 第 1–2 周 | 20 名种子用户；每人体验 3 个场景并生成 1 张手账 | 验证“愿不愿意分享” |
| 第 3–4 周 | 联合心理社团/班级心理委员做 1 次线下体验 | 100 名真实用户 |
| 第 2 个月 | 校园大使 5–10 人；每周 1 个手账主题 | 分享率、扫码率 |
| 第 3 个月 | 3 所校园试点；小范围付费测试 | 留存与付费意愿 |

校园渠道优先级：

1. 心理中心/心理社团；
2. 班级心理委员/辅导员（只做匿名体验，不查看学生对话）；
3. 校园墙/表白墙/树洞类账号（合规合作）；
4. 学生 KOC 的真实使用笔记；
5. 小红书“情绪手账/大学生情绪”话题。

### 13.4 内容与增长节奏

- 每周一个主题：期末焦虑、面试失败、宿舍关系、毕业季、失眠；
- 每期产出：1 张主题手账模板 + 1 条学生故事 + 1 个场景入口；
- 小红书/视频号发“手账制作过程”，不展示用户隐私；
- 落地页提供“先体验”入口，不强制下载；
- 用二维码区分渠道：校园社团、KOC、公众号、线下海报。

### 13.5 激活与留存

| 环节 | 设计 |
| --- | --- |
| 首次打开 | 游客模式 → 选场景 → AI 先开口，3 分钟内完成第一次对话 |
| 首次价值 | 第一次对话后引导生成一张手账，形成“被接住”的记忆点 |
| 次日回访 | 本地通知：“昨天那句话，今天还想接着说吗？” |
| 7 日留存 | 本周情绪/记忆回顾；重要日子提醒 |
| 长期留存 | 记忆可编辑、角色可成长、每周手账连续记录 |

不建议的留存手段：

- 连续签到强迫症；
- 用危机/焦虑制造恐惧；
- 付费才能获得安全资源；
- 强制邀请才能继续聊天。

### 13.6 关键指标

| 指标 | 含义 | 早期目标 |
| --- | --- | --- |
| 激活率 | 下载/扫码后完成首次对话 | ≥ 45% |
| 首次手账率 | 首次对话后生成手账 | ≥ 30% |
| 分享率 | 手账保存后分享到外部 | ≥ 20% |
| 扫码率 | 看到手账后扫码 | ≥ 5% |
| 分享带来的激活 | 扫码后完成首次对话 | ≥ 20% |
| D7 留存 | 7 天后仍使用 | ≥ 25% |
| 付费转化 | 增值功能付费 | 3–8%（验证期） |
| CAC | 单个有效用户获取成本 | 校园期 < 3 元 |

> 这组数字是早期假设，不是承诺；每 2 周用真实数据校准一次。

### 13.7 90 天执行清单

1. 上线 `share/index.html` 落地页，二维码接入；
2. 做 8 张场景手账模板，统一品牌渐变；
3. 找 20 名种子用户，记录“是否保存/是否分享/为什么”；
4. 合作 3 个校园心理社团，做线下体验；
5. 每周发 2 条小红书/视频号内容，连续 8 周；
6. 统计扫码 → 下载 → 首次对话 → 首次手账 → 分享的漏斗；
7. 用数据决定是否做订阅、校园服务或暂缓商业化。

### 13.8 风险与边界

- **隐私**：不做学生对话内容的后台查看；校园版只看匿名聚合数据；
- **安全**：危机场景不生成手账、不做裂变；
- **合规**：不做虚假疗效、不冒充心理咨询；
- **平台规则**：朋友圈/小红书内容避免“治疗、治愈、诊断”表述；
- **依赖**：不鼓励用户只依赖 AI，危机时优先真人资源。

如果你正经历强烈痛苦或危机，请优先联系真人：

- 12356 全国心理援助热线（以当地开通情况为准）
- 120 / 110
- 学校心理中心 / 辅导员
- 身边可信任的人
