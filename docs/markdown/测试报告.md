| 验证项 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| 代理鉴权 | 不带 `Authorization` 请求 `/v1/models` | 401 `unauthorized` | 通过 |
| 错误令牌 | 使用错误 `CLIENT_TOKEN` | 401 `unauthorized` | 通过 |
| 模型白名单 | 请求 `gpt-4o` | 400 `model not allowed` | 通过 |
| 模型列表 | 携带正确令牌请求 `/v1/models` | 200，返回模型列表 | 通过 |
| 非流式对话 | `qwen3.5-omni-plus` + 短消息 | 200，返回正文 | 通过 |
| 流式回复 | `stream=true` | SSE `data:` 分块逐字返回 | 通过 |
| 图片请求 | 2.1MB base64 图片 | 200，正常返回图片描述 | 通过 |
| 请求体大小 | 超过 10MB 的请求体 | 413 `payload too large` | 审计通过 |
| 回复长度上限 | 请求超大 `max_tokens` | 服务端截断到 2048 | 审计通过 |
| APK 密钥扫描 | 解包 `classes*.dex` 搜索 `sk-ws-` | 0 处 | 通过 |
| APK 配置 | 搜索代理地址与令牌 | 只含代理域名与令牌 | 通过 |

代理实现：

```text
App → Cloudflare Worker → 千问 MaaS
       ├─ Authorization: Bearer <CLIENT_TOKEN>
       ├─ ALLOWED_MODELS 白名单
       └─ MAX_TOKENS=2048
```

真实 Key 只保存在 Worker Secret `UPSTREAM_API_KEY`；换 Key 不需要重新打包 APK。

## 七、输入法专项

### 7.1 问题现象

设备默认输入法为：

```text
com.tencent.wetype/.plugin.hld.WxHldService
```

部分情况下第一次聚焦输入框，键盘没有及时弹出。

### 7.2 修复

新增 `keyboardRetryOnFocus()`：

- 输入框获得焦点后延迟 120ms / 300ms / 700ms 重试；
- 不修改系统输入法；
- 不弹出“请更换输入法”提示；
- 应用于聊天、登录/锁屏、我的资料与账户、角色编辑、模型服务。

### 7.3 验证结果

| 场景 | 结果 |
| --- | --- |
| 微信输入法首次聚焦 | 键盘正常弹出 |
| 强制停止微信输入法后重新打开 | 键盘正常弹出 |
| 聊天输入框 | 正常 |
| 锁屏密码框 | 正常 |
| Gboard | 正常 |
| `mInputShown` | true |
| `mImeWindowVis` | 3 |
| 不再出现切换输入法弹窗 | 通过 |
