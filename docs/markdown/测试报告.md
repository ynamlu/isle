## 三、评审复核路径

| 场景 | 操作 | 可观察的预期结果 |
| --- | --- | --- |
| 无 Key 首次使用 | 安装 APK，点「先体验」，查看首页、场景和记忆页 | 可进入应用并查看演示角色及记忆 |
| 聊天返回 | 从首页和场景各进入聊天，分别试顶栏返回、系统侧滑及取消侧滑 | 回到来源页。聊天输入框与底栏不重叠，取消侧滑后继续聊天 |
| 聊天滚动 | 配置模型后发起一段长回复，流式输出时上滑查看历史 | 底部正常显示新内容。上滑后不会因为逐段更新而被拉回 |
| 角色选择 | 在首页和场景页打开「期末复习焦虑」，选择一个角色 | 两处显示相同的角色选择卡，进入对应场景 |
| 恢复码保存 | 用临时本地账户注册，复制恢复码，再点「我已保存」 | 复制有反馈，确认后关闭保存卡 |
| 产品闭环 | 配置自由对话所需模型服务，使用「期末复习焦虑」，查看记忆并尝试保存情绪手账 | 可以开启一轮对话，随后分别进入记忆管理和手账保存 |
| 服务错误 | 使用无效测试配置，点击「测试连接」或发送消息 | 应用提示检查配置，用户可更换设置后重试 |

## 四、复现命令

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest
```

可在依赖已缓存时添加 `--offline`。Android 仪器化测试请使用专用测试设备或模拟器，Gradle 的连机测试流程可能卸载被测应用。真实模型回复与连接结果取决于模型服务、配置和网络。
